# Android: обновление данных

Учебное приложение на Kotlin: профиль пользователя с добавлением и обновлением записей.

**Стек:** Kotlin · Android Studio · Gradle

## Что внутри

- `app/` — приложение
  - `data/` — DTO, репозитории, сервис и широковещательный приёмник
  - `domain/` — модели и use case
  - `presentaition/` — Activity, фрагменты, ViewModel и фабрики

## Запуск

Открыть проект в Android Studio и запустить на эмуляторе или устройстве.
